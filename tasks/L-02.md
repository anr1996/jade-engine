# L-02 - Core interfaces
Model: Pro    Crates owned: engine-core, apps/sandbox    Depends on: L-01

## Goal
engine-core provides the foundation every other crate builds on:
an App that owns a bevy_ecs World and its schedules, a Plugin trait,
and the shared Transform and Time types.

## Allowed dependencies (engine-core only)
- bevy_ecs (current 0.x release)
- glam
apps/sandbox may depend on engine-core by path.

## Create in engine-core
- Stage enum: Startup, FixedUpdate, Update, Render.
- App: owns a bevy_ecs World and one Schedule per Stage.
  Methods: new(), add_plugin(plugin), add_systems(stage, systems),
  insert_resource(value), world(), world_mut(), update().
  update() runs Startup once on the first call, then FixedUpdate,
  Update and Render in that order.
- Plugin trait: fn build(&self, app: &mut App).
- Transform component: translation Vec3, rotation Quat, scale Vec3.
  Default is the identity transform.
- Time resource: delta and elapsed seconds as f32 fields only.
  Task G-01 fills them in later.
- Re-export glam and the bevy_ecs prelude from engine-core.

## Demo
apps/sandbox builds an App with a small example plugin. Startup
prints "startup" once. Update prints "tick N". main calls update()
three times.

## Done when
