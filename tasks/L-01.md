# L-01 - Workspace skeleton
Model: Flash    Crates owned: all (creates them)    Depends on: none

## Goal
Turn this repo into a Cargo workspace. Every crate from the plan
exists as an empty crate, so cargo build works.

## Create
- Root Cargo.toml with [workspace]: resolver = "3",
  members = ["crates/*", "apps/*"].
  [workspace.package]: edition = "2024", version = "0.1.0".
- Library crates in crates/: engine-core, engine-platform,
  engine-render, engine-assets, engine-world, engine-physics,
  engine-anim, engine-audio, engine-ui, game-data, game-sim, game-save
- Binary crates in apps/: sandbox and game. Each main prints its
  own name.
- Every crate's Cargo.toml uses edition.workspace = true and
  version.workspace = true.
- Every lib.rs starts with a one-line //! comment saying what the
  crate will own.
- scripts/check.sh runs fmt check, clippy, then tests, and stops
  at the first failure.

## Done when
- [ ] cargo build --workspace succeeds
- [ ] scripts/check.sh passes
- [ ] cargo run -p sandbox prints "sandbox"
- [ ] tasks/L-01.report.md is written

## Out of scope
No dependencies, no real engine code, no CI service setup.
